# Studiq

A minimalist study planner designed for competitive exams and scalable to any learning process.

## ✨ Features (MVP)

- Daily study plan ("Today")
- Topic management
- PDF library for study materials
- Simple notes per topic
- Progress tracking

## 🧱 Tech Stack

- React Native (Expo)
- TypeScript
- Supabase (PostgreSQL + Storage)
- Zustand (state management)
